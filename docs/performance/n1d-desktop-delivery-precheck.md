# N1-D — 桌面诊断修复与本地交付预检

基线 81341b4；2026-11-25；隔离 Linux x64，Node 22.23.4，pnpm 12.21.0，Electron 44.9.0。

## A08 修复

生命周期事件保留上限不变（默认 128）；已关闭窗口快照新增独立上限，默认与事件上限相同，按关闭顺序淘汰。活跃、隐藏和最小化的窗口不被淘汰。晚到的通知保留为有界事件，但不能恢复已关闭或淘汰的窗口状态。10,000 次模拟注册/关闭循环中，两个活跃窗口及最近 16 个关闭快照始终保留，事件不超过 32 项；共五个专项用例通过。该模拟不是 30 分钟真实桌面内存长测。

实际 Electron 生命周期探针原先在 did-finish-load 后固定等待 100 ms，可能早于异步目录加载和 React 挂载。增加最多 8 秒的挂载条件等待；首次失败为未挂载，修正后已通过挂载检查，但 Xvfb 无原生窗口管理器，未观察到 window-minimize，完整探针仍失败。不取消必需事件断言。
