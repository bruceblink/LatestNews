# Electron 托盘后台刷新计划

日期：2026-10-25。基线：`58a2276`。

## 范围

增加默认关闭的托盘后台模式。启用后，关闭主窗口会隐藏窗口并保留应用进程。系统托盘菜单可以恢复窗口、立即刷新本地来源或退出应用。关闭该模式时，关闭主窗口继续退出应用。

应用窗口隐藏期间，后台按已启用插件提供的来源间隔刷新本地来源并写入现有缓存。窗口再次显示时暂停后台刷新。系统休眠期间暂停计时；恢复后只执行已到期来源，不补跑每个错过的周期。`remote` 模式不启动本地后台采集。托盘后台模式不安装系统服务，也不配置开机启动。

## 验收条件

- 新安装默认不启用托盘后台模式。启用值重启后保留。
- 启用后关闭主窗口只隐藏窗口；托盘可恢复窗口、触发一次本地刷新和退出应用。
- 停用后关闭主窗口退出应用。托盘退出会停止调度器、拒绝新采集并释放 worker。
- 后台仅刷新已启用的本地来源，并遵守来源清单的刷新间隔、现有并发上限和任务超时。
- 窗口显示或系统休眠时暂停调度。恢复后不创建积压任务；每个来源最多有一个活动后台任务。
- `remote` 模式不触发本地后台刷新；改回 `auto` 或 `local` 后，隐藏窗口时可继续刷新。
- 托盘图标缺失时，应用保持可见并报告明确错误，不能隐藏到不可恢复的状态。

## 验证命令

- `pnpm check`
- `pnpm typecheck:electron`
- `pnpm electron:build`
- `pnpm test:e2e:electron`
- 使用 Computer Use 在 Windows 原生窗口检查托盘开关、关闭到托盘、恢复窗口和退出行为。真实后台 HTTP 访问与调度计时单独说明。

本切片不增加外部服务。Docker 集成测试不适用。

## 回退边界

删除托盘设置、托盘菜单和后台调度器即可恢复原窗口关闭行为。保留 Electron 采集模式、本地插件和缓存格式；不删除用户配置或缓存。

## 实现与验证记录

状态：首轮实现完成。托盘菜单的真实点击和公网刷新结果尚未验证。

- `desktop-preferences.json` 保存版本化偏好。托盘后台模式默认关闭。保存失败时会恢复此前状态。
- 启动时托盘初始化失败会关闭本次托盘模式并显示错误。即使无法保存停用值，主窗口仍会启动并保持可见。
- 托盘模式启用后，主窗口关闭时隐藏窗口并保留进程。托盘菜单提供打开、立即刷新本地来源和退出操作。
- 后台调度器只读取已启用插件的来源间隔，并将并发限制为两个来源。窗口显示和系统休眠会暂停调度。恢复后不会补跑每个错过的周期。
- 远端模式阻止本地后台刷新。停用托盘模式或退出应用时会停止调度器、移除系统电源事件监听器并销毁托盘。
- 调度器测试覆盖来源间隔、暂停恢复、错误重试、并发上限、远端模式、手动刷新和停止后不启动新批次。
