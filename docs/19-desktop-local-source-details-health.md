# 桌面本地来源详情与采集健康计划

日期：2026-10-25。基线：`f10a813`。

## 范围

Electron 的来源详情、完整来源目录和来源健康查询遵循远端优先策略。远端地址未配置时直接使用桌面内置来源目录和本地健康记录；远端发生网络错误或 5xx 时回退本地。401、403、429 和普通 4xx 保持为错误。静态来源详情从共用来源清单生成，运行时插件详情从受信任的主进程 bridge 获取。

主进程记录本次运行期间每个已启用本地插件的成功和失败次数、最近状态、最近错误时间及有界事件列表。持久缓存存在时提供最近成功时间和条目数；采集失败后使用缓存时标记缓存降级。健康摘要只描述本地插件，不伪装成完整远端来源统计。

## 实现结果

- 来源目录、静态来源详情和运行时插件详情可在本地生成。插件目录由只读主进程 IPC 返回并通过共享清单校验。
- 本地健康摘要由主进程采集记录生成。成功或失败采集会更新计数、耗时、最近事件和缓存降级状态；错误信息会隐藏 URL 与认证值，事件最多保留 12 条。
- 远端 API 缺少配置时直接用本地数据。远端网络错误或 5xx 时回退本地；401、403、429 和其他 4xx 保持错误。
- 新增健康 IPC 不接受来源 ID、路径或 URL 等渲染器输入，并使用现有可信主窗口校验。

## 验收条件

- 没有远端 API 时，已知静态来源和插件来源都能读取来源目录与详情。
- 网络错误或 5xx 时，来源目录、详情、健康摘要和筛选后的健康列表回退本地；401、403、429 不回退。
- 本地健康读取显示启用的插件来源、初始未采样状态、成功和失败变化，以及缓存回退状态。事件数量有界，错误文本不泄漏上游 URL 和请求细节。
- 所有新增 IPC 只接受可信主窗口，不接受渲染器传入路径或任意来源清单。
- 本地新闻列表、远端优先策略、Web 路由和响应类型保持兼容。
