# N4-O 新闻档案与事件历史验收

日期：2026-11-25。基线：8917caa（PR #19）。环境：隔离 Linux、Node 22.23.4、pnpm 12.21.0、Chromium 和 Electron 44.9.0（Xvfb）。不调用真实生产索引，不调整生产数据或发布。

## 实现边界

- /archive 支持可分享查询条件、来源与 UTC 发布时间起点；每次检索上限 50 条，不冒充总命中数。
- 使用既有 /api/v1/articles/search 与 /api/v1/events/:id；事件详情区分持久 ID 与别名，按游标继续读取、按 articleKey 去重、阻止循环游标。
- 注册事件才从洞察进入历史。保留候选、冲突及不可用身份语义，不新增自动归属。
- 复用收藏、稍后读、已读、隐藏及安全外链；桌面本地模式、网络离线不以 Feed 或本地记录假冒历史结果。401/403/429/404/503 分别显示，分页失败保留已加载记录并允许重试。
- 不改变 schema 或服务器 API 契约；不替换 Ctrl/Cmd+K 来源搜索；移动端通过阅读历史进入档案。
