**初步判断**：提高来源并发降低排队 P95，同时插件执行 P95 上升；端到端冷缓存 P95 仍约 3 秒。短生命周期进程资源竞争是待验证解释，不是已测量的 CPU 根因。不得用本轮结果修改默认并发、取消进程隔离或承诺生产 SLO。与 11 月 22 日不同构建/环境的基准不直接计算改善百分比。
