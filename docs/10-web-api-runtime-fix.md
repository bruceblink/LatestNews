# Web 接口运行时修复

日期：2026-10-24。基线：`13c3c76`。本切片处理本地 `pnpm dev` 的来源接口 HTTP 500。

## 已复现的问题

- 本地来源目录、来源健康和部署健康接口返回 200。
- 单源条目接口在执行采集前返回 500。Node 报告无法解析 `dayjs/esm/index.js` 内部的 `./constant` 引用。
- 项目对 Day.js ESM 的 duration 插件保留定制补丁。直接切换到另一个入口可能改变相对日期解析，不能仅为消除导入错误而切换。

## 实现与验收

- 使用 Nitro 的 `noExternals` 配置编译 Day.js，保留现有入口和补丁。
- Node 生产构建明确指定前端 HTML 模板与 `dist/output` 输出位置，保证前端入口随服务端打包，并与启动命令、Docker 和性能脚本一致。
- 在 Playwright 增加不拦截 API 的回归测试，覆盖来源目录、健康和无效来源条目请求。无效来源应返回 400，不能在加载适配器时返回 500。
- 本地检查真实单源与批量请求，并分别记录源站网络失败与模块加载失败。
- 补充检查发现缓存使用未导入的 `useDatabase`，健康事件表依赖不存在的同名全局函数。两者改为显式导入 `nitro/database`，同时移除会掩盖缺失导入的全局类型声明。验证缓存命中、数据库不可用和健康事件写入，生产启动检查须确认缓存状态为 `ok`。
- 执行定向日期与来源测试、`pnpm lint:check`、`pnpm typecheck`、`pnpm typecheck:electron`、`pnpm test --run`、Web E2E 和生产构建。

## 验证边界

- Browser 插件未提供，页面自动化使用仓库现有 Playwright。
- Computer Use 可以发现真实 Firefox 窗口，但当前浏览器不支持工具要求的 URL 策略检查，工具终止了该路径。本切片的页面验证不能表述为 Computer Use 交互验收。
- 公网部署没有提供日志或部署控制能力。修复本地接口不等于修复线上部署；线上需要部署对应版本后单独检查。
- 未新增数据库或外部服务集成，Docker 服务集成测试不适用。

## 回退边界

撤回 Day.js 编译配置、Node 输出与模板配置和新增 API 回归测试即可回退。不改变源 ID、API 响应格式、缓存、凭据或桌面采集策略。

## 验证结果

- 开发地址：`http://127.0.0.1:5173`。掘金和哔哩哔哩单源接口均返回 200；批量接口返回两个来源各 30 条，`errors` 为空；无效来源返回预期的 400。
- `pnpm test:e2e:web`：4 个测试通过，包括 2 个真实 Nitro API 用例和 2 个页面 smoke 用例。
- `pnpm test --run`：71 个文件、344 个测试通过，其中日期解析 39 个用例保留补丁行为。
- `pnpm lint:check`、`pnpm typecheck`、`pnpm typecheck:electron` 和跳过图标下载的生产构建通过。
- 生产包从临时工作目录启动：首页、`/settings`、前端入口脚本、来源目录和部署健康返回 200，无效来源返回 400。检查后停止临时进程并删除临时目录。
- Playwright 使用真实本地 API 打开 `/source/juejin`，标题为 `LatestNews | 稀土掘金`，页面显示 20 条新闻；设置面板可以打开。1440×1000 和 390×844 截图已检查，移动视口没有横向溢出。
- 控制台没有 JavaScript 运行异常。现有配置指向 `http://localhost:8000/api/me`，该认证服务未运行，产生 `ERR_CONNECTION_REFUSED`；`/api/enable-login` 因未配置登录返回 506。这些认证环境问题不属于新闻接口修复通过的范围。

上述结果不替代线上部署验收。线上接口首轮采样仍保留为 HTTP 500，须部署并复查后更新记录。
